# TODO — Quiz Bot

## Сбор реакций пользователей на вопросы

**Цель**: позволить пользователям оценивать вопросы через Telegram-реакции (👍/👎), чтобы собирать фидбек о качестве контента.

**Как работает**: бот отправляет вопрос → пользователь ставит реакцию → бот получает `message_reaction` update → по `message_id` находит вопрос в `answerLog` → сохраняет фидбек.

### Шаги реализации

1. **Схема `answerLog`** — добавить поле `messageId: v.optional(v.number())` и индекс по `chatId` + `messageId` для быстрого поиска
2. **Сохранение `messageId`** — при отправке вопроса (`sendMessage`/`sendPhoto` возвращает `Message` с `message_id`) записывать его в `answerLog` при создании записи
3. **Webhook `allowed_updates`** — добавить `"message_reaction"` в список при вызове `setWebhook`
4. **Обработчик реакций** — `bot.on("message_reaction", ...)`:
   - Получить `message_id` и `chat.id` из `ctx.messageReaction`
   - Найти запись в `answerLog` по `chatId` + `messageId`
   - Обрабатывать только 👍 и 👎, остальные реакции игнорировать
   - Сохранить фидбек (новое поле в `answerLog` или отдельная таблица)
5. **Хранение фидбека** — решить: добавить поле `reaction` в `answerLog` или создать отдельную таблицу `questionFeedback`

### Детали и ограничения

- Bot API 7.0+ — реакции поддерживаются
- В личных чатах работает из коробки, `user` всегда доступен
- В группах бот должен быть администратором для получения `message_reaction`
- Ограничить доступные реакции в личном чате нельзя — только фильтрация на стороне бота
- Бот видит реакции только на свои сообщения
- `new_reaction` — массив `ReactionType`, каждый элемент: `{ type: "emoji", emoji: "👎" }`
