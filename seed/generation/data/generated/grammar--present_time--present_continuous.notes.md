## Покрытие KC

KC: Present Continuous (сейчас): am/is/are + -ing. Вопросы: «She ___ (read) now» → is reading.

| Аспект | Покрыт | Вопросы |
|--------|--------|---------|
| I=am форма | ✓ | 28 (am driving), 37 (am reviewing), 40 (am packing) |
| she/he=is форма | ✓ | 29 (is swimming), 43 (is singing), 44 (is watching), 49 (is turning), 51 (is snowing), 53 (is stopping) |
| we/they=are форма | ✓ | 31 (are making), 52 (are building) |
| you=are форма | ✓ | 66 (aren't using) |
| Who + PC | ✓ | 4 (Who is sitting — is vs are ловушка) |
| Отрицание (aren't) | ✓ | 66 (aren't using) |
| Правописание: CVC двойная согласная | ✓ | 29 (swim→swimming), 53 (stop→stopping) |
| Правописание: drop-e | ✓ | 31 (make→making, дистрактор makeing) |
| Правописание: ie→y | ✓ | 47 (lie→lying, + ловушка laying) |
| Everyone/someone + is (ед. число) | ✓ | 48 (everyone is waiting), 62 (someone is shouting) |
| PC для запланированного будущего | ✓ | 9 (tonight = план) |
| PC для постепенного изменения | ✓ | 49 (is turning red) |
| Погода (it is snowing) | ✓ | 51 (is snowing) |
| Фразовый глагол в PC | ✓ | 41 (am looking for) |

**Чего не хватает:**
- am not / isn't (отрицание 1-го и 3-го лица; только aren't покрыто через row 66)
- Вопросительная форма Is she...? / Are they...? (только Who-вопрос)
- Stative verbs (think, know, want, smell — глаголы, не употребляемые в PC): ни один вопрос не покрывает эту ловушку
- run→running (CVC удвоение r): упоминается в объяснениях row 46, но нет отдельного вопроса

## Рекомендации по промпту

**kimi-k2.5** (строки 28–54): самый высокий показатель отбора (52%). Голоса авторов живые и индивидуальные, сценарии разнообразны. Незначительное смешение языков в репликах (английские восклицания у colleague) — допустимо как авторский стиль. **Рекомендуется оставить как основную модель.**

**minimax-m2.5** (строки 0–27): качество неравномерное. Строка 5 — китайский иероглиф в объяснении (та же проблема, что и в present_simple). Строки 9, 4 — хорошие вопросы, но остальные 26 однотипны. **Рекомендуется оставить с добавлением в промпт: «Все объяснения строго на русском, без символов из других языков».**

**google/gemma-4-31b-it** (строки 55–77): строки 38–39 от office — все объяснения на английском (то же нарушение, что у minimax в present_simple). Для этой модели проблема системная. Остальные вопросы технически корректны, но голоса авторов однообразнее, чем у kimi. Отобраны только row 62 (someone=is, уникальный аспект) и row 66 (aren't, единственное отрицание). **Рекомендуется исключить из генерации, заменив kimi или добавив minimax с исправленным промптом.**

**Общая рекомендация:** kimi-k2.5 стабильно лучший результат по качеству голоса и разнообразию сценариев. Для KC Present Continuous не хватает вопросов на stative verbs и вопросительную форму (Is she...?) — стоит добавить в промпт явное требование покрыть эти аспекты.
