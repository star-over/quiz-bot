# Рецензия: grammar/present_time/have_got

**Дата:** 2026-04-03
**Входных вопросов:** 109 (9 авторов × 5 моделей)
**Отобрано:** 18

## Покрытие KC

KC `grammar/present_time/have_got` (A1) покрывает конструкцию владения have got / has got:

1. **Утвердительная форма has got (he/she/it)** — покрыто хорошо:
   - popculture (Добби из Гарри Поттера)
   - provocateur (колонка в газете)

2. **Утвердительная форма have got (I/you/we/they)** — покрыто:
   - child (динозавры — plural)
   - colleague (team — собирательное существительное)

3. **Вопросительная форма Has/Have...got?** — покрыто:
   - methodist (Has your brother got — 3 л. ед.ч.)
   - colleague (Have they got — plural)

4. **Отрицательная форма hasn't/haven't got** — покрыто хорошо:
   - methodist (haven't got для you)
   - trap (haven't got, составное подлежащее)
   - traveler (haven't got для plural; hasn't got для it)
   - narrator (hasn't got для he)
   - popculture (hasn't got для it)
   - office (hasn't got в деловом контексте)

5. **Ловушки на согласование**:
   - trap (everyone + has got — «ложное мн.ч.»)
   - provocateur (no one + has got — «ложное мн.ч.» + двойное отрицание)
   - child (every robot + has got)
   - office (every conference room + has got)
   - narrator (составное подлежащее David and Kenji)
   - colleague (собирательное team)

**Баланс:** 5 утверждений, 7 отрицаний, 2 вопроса, 4 ловушки на согласование. Хорошее разнообразие форм.

**Подлежащие:** he (3), she (0 — косвенно через provocateur «column»), it (4), you (1), we (0 — в составных), they (2), составные (2), every/no one/everyone (4). Широкое покрытие.

**Не хватает:** Утвердительная форма для I (первое лицо ед.ч.) — можно добавить при следующей генерации.

## Рекомендации по промпту

### Желательные

1. **Разнообразие форм**: модели массово генерируют утвердительные предложения с has got для 3-го лица. Стоит добавить в промпт явное требование:
   > Обязательно включите: 1 вопрос на вопросительную форму (Has/Have...got?), 1 на отрицание (hasn't/haven't got), 1 на ловушку согласования (everyone, compound subjects, collective nouns).

2. **Разнообразие подлежащих**: почти все вопросы — he/she/it. Слабо покрыты we, you, I. Попросить модели чередовать лица.

3. **Избыток однотипных сценариев**: из 109 вопросов ~75 тестируют один и тот же грамматический паттерн (has got affirmative). При генерации 3 вопросов на автора из них получается только 1 уникальный. Снизить лимит или усилить инструкцию по разнообразию.

4. **`<code>` в choices**: модель gemini-2.5-flash иногда оборачивает prompt и choices в `<code>`/`<pre>`. Добавить явный запрет: `Не используй <code>, <pre> в prompt и choices[].content`.
