## Покрытие KC

KC: Present Simple — форма + -s/-es в 3-м лице; Do/Does в вопросах (A1)

| Аспект | Покрыт | Вопросы |
|--------|--------|---------|
| Утверждение: -s в 3-м лице | ✓ | 79 (makes), 17 (leaves) |
| Орфография: -es после шипящих | ✓ | 47 (watches), 66 (teaches) |
| Орфография: -ies (согласная+y) | ✓ | 28 (studies), 53 (flies) |
| Does в вопросе (3-е лицо) | ✓ | 52 (Does she), 67 (Does she speak), 43 (How does she) |
| Do в вопросе (I/you/we/they) | ✓ | 37 (Do you), 8 (do they go), 41 (does it take) |
| Отрицание doesn't | ✓ | 22 (doesn't go), 31 (Does he have → базовая форма) |
| Вопрос к подлежащему (Who + -s) | ✓ | 6 (Who lives), 13 (Who drives) |
| Краткие ответы | ✓ | 30 (Yes, he does), 49 (No, she doesn't) |
| Двойное do (does + смысловой do) | ✓ | 46 (does...do) |
| Ловушки: everyone/each | ✓ | 85 (everyone knows), 101 (each of us understands) |

**Чего не хватает:**
- go → goes (особое окончание после o): вопрос 35 удалён из-за объяснений на английском
- Don't для I/we/they отдельным вопросом (есть косвенно через 8, 37)
- Orфография: глаголы на -ss/-x/-sh (-es)

## Рекомендации по промпту

**minimax-m2.5** (строки 0–27): хорошее качество голосов авторов, но иногда вставляет иноязычные символы в объяснения (строка 7 — китайский). Рекомендуется добавить в промпт: «Все объяснения строго на русском, без слов из других языков кроме английских грамматических примеров».

**moonshotai/kimi-k2.5** (строки 28–54): хорошее качество, голоса живые. Незначительное смешение языков (английские восклицания в объяснениях) — допустимо как авторский стиль.

**z-ai/glm5** (строки 55–81): в целом качественно. Строка 58 содержит choices.content на русском ("вопрос без глагола") — нарушение формата.

**google/gemma-4-31b-it** (строки 82–108): технически точные, но голоса авторов менее индивидуальные по сравнению с другими моделями. Объяснения более "учебниковые". Лучший результат — сложные ловушки с everyone/each/nobody/police/family (строки 85–87, 101–102).

**Общая рекомендация:** Все три задействованные модели справляются с KC. Для более живого голоса авторов minimax-m2.5 и kimi-k2.5 показывают лучший результат. Для сложных грамматических ловушек (collective nouns, indefinite pronouns) gemma-4-31b даёт более системные объяснения.
