| `grammar/modality/must_vs_have_to` | must (внутренняя необходимость) vs have to (внешняя). 'I must study' (сам) vs 'I have to' (требование). |

| `grammar/passive/past_simple` | Past Simple Passive: was/were + V3. 'The book ___ (write) in 1900' → was written. |

| `grammar/determiners/much_many_a_lot_of` | much (несчётные, в отрицании/вопросе) vs many (счётные) vs a lot of (оба, в утверждении). |
| `grammar/determiners/a_few_a_little` | a few (немного, счётные) vs a little (немного, несчётные). Выбор по типу существительного. |
| `grammar/pronouns/reflexive` | Возвратные местоимения: myself/yourself/himself... 'She hurt ___' → herself. By myself = один. |

| `grammar/adjectives/ing_ed_participle_basic` | -ing (о вещи) vs -ed (о человеке). 'The film was boring / I was bored.' Выбор формы. |
| `grammar/adjectives/so_such` | so + adj/adv vs such (a/an) + noun. 'It was ___ a good film' → such; 'It was ___ good' → so. |
| `grammar/adjectives/enough_too` | too (слишком, негативно) vs enough (достаточно). Позиция: too перед, enough после прилагательного. |
| `grammar/adverbs/manner` | Наречия образа действия: суффикс -ly, исключения (well, fast, hard). Позиция после объекта. |
| `grammar/prepositions/movement` | Предлоги движения: to, into/out of, through, past, along, across. 'She went ___ the room' → into. |
| `grammar/prepositions/time_before_after_during` | during + noun vs while + clause. '___ the film, I fell asleep' → During (не while + noun). |
| `grammar/questions/question_tags_basic` | Разделительные вопросы: инверсия. 'You're a student, ___ you?' → aren't. Утверждение → отриц. тег. |
| `grammar/questions/there_is_are` | there is/are для существования. '___ a book on the table' → There is. Вопросы/отрицания. |
