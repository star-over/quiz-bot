### Методология

- **grammar:** English Grammar Profile (EGP, 1239 дескрипторов) + Murphy «English Grammar in Use». Один KC = один teachable концепт.
- **vocab:** только слова с высоким риском ошибки для русскоговорящих: пары-паронимы, ложные друзья, трудные паттерны употребления.
- **collocation:** verb+noun, adjective+preposition — зоны высокой русской интерференции.
- **spelling:** слова с документально высоким процентом ошибок, включая омофоны и апострофные пары.
- **Уровень CEFR** — метаданные KC, не часть идентификатора.

### Поля описания

Каждое описание закрывает два вопроса:
1. **Проблема** — какой именно навык/знание тестируется, в чём трудность для русскоговорящих
2. **Вопросы** — типичные форматы заданий, примеры пробелов/выборов

## Грамматика — grammar

### A1

| KC | Описание |
|----|---------|
| `grammar:present_time:be_am_is_are` | Выбор правильной формы глагола-связки **be** (am/is/are) по подлежащему. В русском нет связки в настоящем времени — русскоговорящие пропускают или путают. Вопросы: вставить форму («___ you a teacher?» → Are), исправить ошибку («He am happy»), выбрать из am/is/are. |
| `grammar:present_time:have_got` | Конструкция **have got** для выражения владения; форма has got в 3-м лице. Вопросы: «She ___ a car» → has got; вопрос «Have you got...?»; отрицание «I haven't got». |
| `grammar:present_time:present_simple` | Образование Present Simple: основная форма + окончание **-s/-es** в 3-м лице ед.ч. Вопросы: «She ___ every day» → works; вопросы с Do/Does; отрицания don't/doesn't. |
| `grammar:present_time:present_continuous` | Образование и значение Present Continuous (действие сейчас): **am/is/are + -ing**. Вопросы: «She ___ (read) now» → is reading; вставить форму be. |
| `grammar:past_time:be_was_were` | Past Simple от **be**: was (I/he/she/it) vs were (you/we/they). Вопросы: «Yesterday she ___ tired» → was; «They ___ late» → were; короткие ответы. |
| `grammar:past_time:past_simple_regular` | Образование Past Simple правильных глаголов: основа **+ -ed**. Правила написания: stop→stopped, study→studied. Вопросы: вставить форму, выбрать правильную форму из вариантов. |
| `grammar:past_time:past_simple_irregular` | Формы неправильных глаголов в Past Simple: go→went, have→had, see→saw, come→came и др. Вопросы: выбрать правильную форму, вставить V2 неправильного глагола. |
| `grammar:future:going_to` | **going to** для планов и намерений. Структура: am/is/are going to + V. Вопросы: «I ___ visit my friend tomorrow» → am going to; выбрать going to vs will. |
| `grammar:future:will_basic` | **will** для прогнозов и спонтанных решений. Форма: will + bare infinitive (без изменений для всех лиц). Вопросы: «It ___ rain» → will rain; «I'll help you» — when to use will. |
| `grammar:modality:can_ability` | **can** для обозначения способностей и умений. Вопросы: «She ___ swim» → can; «Can you speak English?» → Yes, I can; выбрать can/can't. |
| `grammar:modality:can_permission` | **can/can't** для разрешения и запрета. Вопросы: «___ I leave early?» → Can; can vs may (формальность); «You ___ park here» → can't. |
| `grammar:modality:could_past_ability` | **could** как прошедшая форма can (способность в прошлом). Вопросы: «When I was 5, I ___ read» → could; could vs was able to. |
| `grammar:modality:imperative` | Повелительное наклонение: основа глагола без подлежащего. Вопросы: «___ the door!» → Open/Don't open; выбрать форму; imperative vs «you should». |
| `grammar:modality:would_like` | **would like** для вежливых просьб и предложений. Вопросы: «I ___ a coffee» → would like; «Would you like...?»; would like vs want (регистр). |
| `grammar:nouns:singular_plural` | Правила образования множественного числа: +s, +es, -y→-ies. Вопросы: box→boxes, city→cities; выбрать правильную форму. |
| `grammar:nouns:countable_uncountable_basic` | Базовое разграничение счётных и несчётных: нельзя **a/an** с несчётными (water, advice, information). Вопросы: «Give me ___ advice» → some (не an advice); выбрать правильный артикль/квантор. |
| `grammar:nouns:possessive_s` | Притяжательный падеж: **'s** для владельца. «Tom___ book» → Tom's; «The children___ toys» → children's. Вопросы: вставить правильную форму, выбрать из вариантов. |
| `grammar:determiners:a_an` | Выбор **a** vs **an**: a перед согласным звуком, an перед гласным звуком. «___ umbrella» → an; «___ university» → a (звук /j/). Вопросы: вставить a/an. |
| `grammar:determiners:the_basic` | Определённый артикль **the**: когда использовать (второй раз в тексте, единственный предмет). «___ sun», «___ cat is on the mat». Вопросы: вставить the/a/-. |
| `grammar:determiners:this_that_these_those` | Указательные местоимения: ед./мн., близко/далеко. «___ book here» → This; «___ books there» → Those. Вопросы: выбрать правильное указательное. |
| `grammar:determiners:how_much_how_many` | **How much** (несчётные) vs **how many** (счётные). «___ money?» → much; «___ students?» → many. Вопросы: выбрать much/many. |
| `grammar:pronouns:subject_pronouns` | Личные местоимения в роли подлежащего: I/you/he/she/it/we/they. «___ am a doctor» → I; замена существительного. Вопросы: выбрать правильное местоимение. |
| `grammar:pronouns:object_pronouns` | Личные местоимения в роли дополнения: me/you/him/her/it/us/them. «Give ___ the book» → me/him/them. Вопросы: выбрать object pronoun. |
| `grammar:pronouns:possessive_adjectives_my_your` | Притяжательные прилагательные: my/your/his/her/its/our/their. «___ name is Anna» → My/Her. Вопросы: выбрать правильное притяжательное. |
| `grammar:adjectives:position_before_after_noun` | Позиция прилагательного: в английском ПЕРЕД существительным (не после, как в русском). «a ___ car» → beautiful car; «The car is ___». Вопросы: исправить порядок слов. |
| `grammar:adjectives:comparative_superlative_basic` | Сравнительная и превосходная степень: -er/-est vs more/most. taller/the tallest; more beautiful/the most beautiful. Вопросы: образовать форму, выбрать правильную. |
| `grammar:adverbs:frequency_always_never` | Наречия частоты (always/usually/often/sometimes/rarely/never) и их позиция: ПЕРЕД смысловым глаголом, ПОСЛЕ be. «She ___ late» → is always / never is. Вопросы: вставить наречие в правильную позицию. |
| `grammar:prepositions:place_in_on_at` | Предлоги места: **in** (внутри пространства), **on** (на поверхности), **at** (точка/место). «___ a box» → in; «___ the table» → on; «___ the door» → at. Вопросы: выбрать предлог. |
| `grammar:prepositions:time_in_on_at` | Предлоги времени: **in** (месяц/год/утро), **on** (день/дата), **at** (время/ночь). «___ Monday» → on; «___ 5 o'clock» → at; «___ June» → in. Вопросы: выбрать предлог. |
| `grammar:questions:yes_no_basic` | Общие вопросы и краткие ответы с Do/Does/Is/Are/Can. «___ you like coffee?» → Do; «Yes, I ___» → do. Вопросы: составить вопрос, выбрать краткий ответ. |
| `grammar:questions:wh_questions` | Специальные вопросы: What/Where/When/Who/Why/How + вспомогательный + подлежащее + глагол. «___ do you live?» → Where; порядок слов в вопросе. |

| `grammar:passive:present_simple` | Present Simple Passive: **am/is/are + V3**. «English ___ (speak) here» → is spoken. Вопросы: трансформировать в passive, вставить правильную форму be + V3. |

| `grammar:nouns:compound_nouns` | Составные существительные: toothbrush, car park, football. Ударение на первый элемент. Вопросы: выбрать правильное написание (слитно/раздельно), определить значение. |
| `grammar:nouns:irregular_plurals` | Неправильные формы мн.ч.: child→children, man→men, foot→feet, mouse→mice, sheep→sheep. Вопросы: выбрать правильную форму мн.ч. |
| `grammar:determiners:some_any` | **some** (утверждение, предложение) vs **any** (отрицание, вопрос). «I have ___ money» → some; «Do you have ___ questions?» → any. Вопросы: выбрать some/any. |
| `grammar:determiners:much_many_a_lot_of` | **much** (несчётные, чаще в отрицании/вопросе) vs **many** (счётные) vs **a lot of** (оба, в утверждении). «There isn't ___ time» → much. Вопросы: выбрать квантор. |
