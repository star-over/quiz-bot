# Исследование: инструменты для редактирования Excel из AI-агента

Дата: 2026-04-01

## Задача

Найти инструмент (CLI, MCP, библиотека) для эффективного редактирования больших файлов Microsoft Excel (.xlsx, опционально .xlsb) из AI-агента. Операции: чтение/запись ячеек, добавление/удаление строк и столбцов, копирование данных между книгами, сохранение форматирования.

---

## 1. MCP-серверы

| Сервер | Бэкенд | .xlsx | .xlsb | Ключевые возможности | Ограничения |
|--------|--------|-------|-------|---------------------|-------------|
| **haris-musa/excel-mcp-server** | Python (openpyxl) | Да | Нет | Полный CRUD, формулы, графики, pivot-таблицы, условное форматирование, стили. Транспорт: stdio, SSE, streamable HTTP | Нет .xlsb. Нет стриминга для огромных файлов |
| **negokaz/excel-mcp-server** | TypeScript (ExcelJS) | Да | Нет | Чтение/запись ячеек, формулы, создание/копирование листов, форматирование, пагинация для больших файлов. На Windows: live-редактирование через COM | Нет .xlsb. Windows-фичи требуют установленный Excel |
| **sbroenne/mcp-server-excel** | .NET (COM API) | Да | **Да** | 25 инструментов, 230 операций. Power Query, DAX, VBA-макросы, PivotTables, графики. Нулевой риск повреждения файлов (нативный COM) | **Только Windows**. Требует установленный Excel. Самое тяжёлое решение |

**Рекомендация**: `haris-musa/excel-mcp-server` — лучший кроссплатформенный выбор, самый богатый набор операций, не требует Excel.

## 2. Node.js / TypeScript библиотеки

| Библиотека | npm weekly | .xlsx | .xlsb | Чтение | Запись | Модификация | Стриминг | Стили | Формулы | Статус |
|-----------|-----------|-------|-------|--------|-------|-------------|----------|-------|---------|--------|
| **ExcelJS** | ~1.9M | Да | Нет | Да | Да | Да | Да (WorkbookReader/Writer) | Полные (шрифты, границы, заливки, выравнивание) | Да | Активен (v4.4.0, Dec 2024) |
| **SheetJS CE** (xlsx) | ~7.8M | Да | **Да** (чтение+запись) | Да | Да | Да | Ограниченный | **Нет** (CE теряет стили; Pro — платный) | Да | Застой (последний релиз Mar 2022) |
| **xlsx-populate** | ~120K | Да | Нет | Да | Да | Да (хорошо сохраняет существующий контент) | Нет | Сохраняет существующие | Да | Не поддерживается с 2020 |
| **excel4node** | ~80K | Да | Нет | Нет | Да | Нет | Нет | Да | Да | Не поддерживается с 2020, только запись |

**Лучший выбор для TS**: **ExcelJS** — стриминг для больших файлов (~140K строк за ~6с), полный контроль стилей, чтение + запись + модификация. Если нужен .xlsb — добавить SheetJS CE для парсинга.

## 3. Python библиотеки

| Библиотека | .xlsx | .xlsb | Чтение | Запись | Модификация | Стриминг | Стили | Скорость | Статус |
|-----------|-------|-------|--------|-------|-------------|----------|-------|----------|--------|
| **openpyxl** | Да | Нет | Да | Да | Да | Да (read_only/write_only) | Полные | Средняя (200K строк ~9мин с стилями) | Активен, де-факто стандарт |
| **XlsxWriter** | Да | Нет | Нет | Да | Нет | Да (constant memory) | Полные (графики, спарклайны, условное форм.) | Быстрая (200K строк ~3мин) | Активен |
| **python-calamine** | Да | **Да** | **Да** | Нет | Нет | Lazy loading | Нет | **Самая быстрая** (5× openpyxl, Rust-ядро) | Активен |
| **xlwings** | Да | **Да** | Да | Да | Да | N/A (COM) | Полные (через Excel) | Зависит от Excel | Активен. Требует Excel (macOS/Windows) |
| **pylightxl** | Да | Нет | Да | Да | Ограниченная | Нет | Нет | Быстрая (минимальный overhead) | Активен, zero-dependency |

**Лучшая Python-комбинация**:
- Чтение .xlsb: **python-calamine** (самый быстрый)
- Генерация .xlsx: **XlsxWriter** (самый быстрый writer с полными стилями)
- Модификация существующих .xlsx: **openpyxl** (единственный реальный вариант для modify-in-place)

## 4. CLI-инструменты

| Инструмент | .xlsx | .xlsb | Описание | Применение |
|-----------|-------|-------|----------|-----------|
| **LibreOffice `--headless`** | Да | Да | `soffice --headless --convert-to xlsx`, выполнение макросов. Может открыть/редактировать/сохранить любой формат Excel | Самый мощный CLI. Тяжёлый старт (~2-3с). Подходит для batch-операций |

## 6. Рекомендуемые паттерны

### Паттерн A — MCP-сервер (лучший для AI-агента)

```
haris-musa/excel-mcp-server → агент вызывает write_cell, add_row, create_chart через MCP
```

Лучше всего для итеративного редактирования, когда агент сам решает что делать на каждом шаге. Устанавливается за минуту.

### Паттерн B — TS-скрипт с ExcelJS (родная экосистема)

```
ExcelJS для всех .xlsx операций + SheetJS CE для чтения .xlsb (если нужно)
```

Программное решение без внешних зависимостей. Стриминг для больших файлов.

### Паттерн C — Python-подпроцесс из Node

```
Node-оркестратор → spawn python-скрипт
  - calamine для .xlsb чтения
  - openpyxl для модификации существующих файлов
  - XlsxWriter для генерации новых
```

Лучшая производительность и максимальное покрытие форматов.

### Паттерн D — LibreOffice headless

```
soffice --headless --macro "macro:///Standard.Module1.EditSheet" file.xlsx
```

Максимальная совместимость с форматами. Подходит для batch-операций, не для высокочастотных вызовов.

---

## 7. Итоговая рекомендация

1. **Для использования из Claude Code** → MCP-сервер `haris-musa/excel-mcp-server`
2. **Для скриптов в TS-проекте** → **ExcelJS**
3. **Для .xlsb** → **python-calamine** (чтение) или **SheetJS CE** (чтение без стилей)
